## 3. coordinator 변경

- `app_main()`이 runtime adapter를 열기 전에 필수 `enter_safe_state`/`idle` callback을 검증하고 safe state를 먼저 적용한다. safe/preflight failure, null callback, open failure에서 report/feed/re-init가 발생하지 않는다.
- ESP runtime의 watchdog은 global TWDT 설정을 가로채지 않고 current task subscription만 요청한다. feed는 reset 전후 시간을 확인하며 post-call timestamp를 core에 전달한다.
- fault 뒤 `sample_valid=false`를 유지해 stale memory/heap/GPIO 값을 정상 snapshot으로 보이지 않게 한다.
- Communicator와 Bridge를 실제 generated Bridge BSP/runtime까지 연결하는 host integration CTest를 추가했다. 이 fixture는 SDK API model이며 physical board/HIL이 아니다.
- ESP-IDF 6.0.3에서 산출된 Communicator/Bridge `sdkconfig` key union을 [allowlist](../../../tools/sdkconfig-allowlist/esp32s3-idf-6.0.3.keys)으로 고정하고, unknown active key·삭제된 required-disabled line·Flash selector·forbidden mutation을 독립 시험한다.
- Bridge USB DM/DP의 package pin 13/14, `USB_D-/USB_D+`, bidirectional type와 generated GPIO 19/20을 generator contract로 묶었다.
