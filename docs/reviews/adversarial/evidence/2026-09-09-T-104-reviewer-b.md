3. **B-03 — P2: Time synchronization rejects legitimate independent clock epochs.**

4. **B-04 — P2: Time-sync COMMIT is not bound to STM’s recorded measurements.**

   Locations:

   - `F:/dev/canview-wt/2026-09-09-t104-review-b/firmware/communicator/stm32/module/uart_link.c:1034`
   - `F:/dev/canview-wt/2026-09-09-t104-review-b/firmware/communicator/stm32/module/uart_link.c:1071`

   The response emits STM timestamps, but pending state retains only identity, generation, token, and t1. COMMIT supplies t2/t3 without comparison against locally retained measurements. Exchange age is also not checked before marking the mapping freshly updated.

   Failure scenario: The test’s request is processed at STM time 5,000 µs; its later successful COMMIT supplies t2=t3=6,000 µs. The implementation accepts that replacement. A delayed outstanding exchange can likewise be committed later and assigned the current `updated_ms`.

   Impact: Mapping provenance and freshness are weaker than the four-timestamp contract implies. Time sync does not invoke the command authorizer. This review does **not** claim a vehicle-TX exploit: the target application supplies a NULL authorizer and retains capture-only restrictions.

   Recommendation: Retain and verify local exchange timestamps, enforce a bounded exchange age, define generation replacement rules, and account for the actual response transmission timing. Add altered-measurement and delayed-commit tests.

5. **B-05 — P2: One abandoned synchronization exchange can block subsequent synchronization indefinitely.**

   Location: `F:/dev/canview-wt/2026-09-09-t104-review-b/firmware/communicator/stm32/module/uart_link.c:986`

   Failure scenario: A REQUEST is accepted, then its response or COMMIT is lost. `pending_sync_valid` remains set. Requests with a new token, Controller boot ID, or generation return BUSY. Normal tick maintenance expires the established mapping but never expires the pending exchange. Continuing valid ESP heartbeats prevents session reset.

   Impact: A normal packet-loss or Controller-reboot event can prevent mapping refresh indefinitely until broader link reset.

   Recommendation: Add a pending-exchange deadline, bounded retry behavior, and explicit replacement/cancellation rules for Controller reboot. Test loss at every exchange phase while heartbeats continue.
