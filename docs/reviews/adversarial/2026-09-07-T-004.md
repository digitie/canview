## 4. 검증 의미와 남은 gate

기존 24시간 Python virtual-time 출력과 1,728,000개 C heartbeat 시험은 full-rate 바이트 부하 증거가 아니었다. `027b22e`의 C soak는 방향당 실제 feed 바이트를 64-bit로 계수하고 정상 frame 수, 손상·삭제·삽입·oversize, guard와 delimiter 복구 상태를 검사한다. start/stop bit를 포함한 공식은 `4,000,000 / 10 × 86,400 = 34,560,000,000 byte/direction`이다. B `027b22e` 원문의 여분 `×10`은 B `3c6967a` 원문에서 정정했다.

STM32/ESP32 target compile은 실제 설치한 Arm GNU15.3.Rel1, CubeG4 1.6.3, ESP-IDF6.0.3으로 수행했다. target binary의 작은 크기는 scaffold의 dead-strip 결과도 포함하며 UART DMA 또는 CAN runtime이 연결됐다는 뜻이 아니다. physical UART·보드 flash/boot·reset/brownout·CAN/RF/HIL·production provisioning·차량은 NOT_RUN이다.
