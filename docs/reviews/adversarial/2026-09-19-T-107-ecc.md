## 재현과 수정 중인 근거

A-01은 post-load RDERR 주입 시험을 먼저 추가해 기존 C가 실패하는 것을 재현했다.
`build/t107-ecc-rderr-reproduced.log`의 반환 상태 assertion 실패를 보존한다.
수정은 각 load 이후 SR 검사, 오류 보존·출력 불변, 예상 밖 BSY의 SRAM fail-stop이다.
첫 오류 모형 assertion/CRT abort는60초 timeout됐고 해당 시험 process만 종료했다.
주입 오류를 모형의 허용 상태에 반영한 뒤 위 반환 오류 재현을 수행했다.

B-01은 조건 suffix를 해석하고 link 간접 branch는 LR도 거절하도록 수정했다.
실제 Arm assembler가 만든 bxne/blxne/blx lr object 거절과 bx lr 정상 객체를 확인한다.
B-02는 stamp 체계 대신 archive가 의존하는 작은 항상 실행 검사 target으로 바꿨다.
소스 변경 없는 재빌드에서도 실제 object 검사/negative object3시험이 재실행됐다.
로그: `build/t107-io-ecc-post-primary-{debug,release}.log`,
`build/t107-ecc-recheck-no-source-change.log`.

새 IO primitive 연결은 최초 리뷰와 별도 진행한 delta이므로 post-fix 재검토 manifest에
추가한다. 최초 guarded read 판정으로 IO/boot 전체를 승인하지 않는다.
